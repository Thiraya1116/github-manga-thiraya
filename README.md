## Ep.6 The-End 

ขณะที่น้องจิ้งจอกกำลังเดินไปหาคนๆนั้นอย่างมุ่งมั่นไม่แม้แต่จะสนใจคนรอบข้าง ในใจของเขารุ่มร้อนไปหมด ความคิดที่อยากจะเจอคนตรงหน้านั้นมากมายเหลือเกิน 

เงาคนตรงหน้าจากขนาดที่เล็กจนเห็นเพียงเลือนลาง เริ่มขยายใหญ่ขึ้นเรื่อยๆ จิตใจของน้องจิ้งจอกมีแต่ความคิดถึง ความเสียใจ และความรู้สึกผิดทุกย่างก้าวที่เดิน

ทันทีที่ได้สบสายตา น้ำตาที่เคยเก็บซ่อนเอาไว้เริ่มเอ่อล้นจนหยุดไม่อยู่ 

"บอส.."

คนตรงหน้ายิ้มให้น้องจิ้งจอกอย่างอ่อนโยนเหมือนเคย ในจักรวาลนี้คนที่รู้ว่าอนาคตจะเกิดอะไรขึ้น ก็มีแต่ตัวของน้องจิ้งจอกเองเท่านั้น มันยิ่งทำให้เขารู้สึกเจ็บปวดเป็นที่สุด 

เสียงนุ่มๆ ของบอสเอ่ยออกมาอย่างอ่อนโยน นี่เขาเข้าใจคนๆนี้ผิดได้ยังไงกันนะ?

"หืม? มีอะไรหรอ?"

น้องจิ้งจอกไม่ได้ตอบอะไรกลับไป แค่น้ำตาที่ไหลลงอาบแก้มก็ไม่มีเวลาจะไปตอบอะไรได้ ทำให้คนตรงหน้าได้แต่งุนงงกับสถานการณ์ที่เกิดขึ้น แต่บอสก็ไม่ได้เซ้าซี้อะไรมากนัก เขาลูบหัวน้องจิ้งจอกอย่างเบามือด้วยความเป็นห่วงโดยไม่ได้พูดอะไร แม้น้ำหนักที่มือของบอสจะเบามากแค่ไหน แต่ในใจของน้องจิ้งจอกกลับหนัก.. หนักมากๆเหลือเกิน


ในที่สุด เขาก็ได้เจอกับบอสของเขาสักที 


จนท้ายที่สุด ในตอนที่สายน้ำไหลอาบแก้มของน้องจิ้งจอกหยุดลง ความสุขุมก็เริ่มกลับมา น้องจิ้งจอกเงยหน้ามองบอส เมื่อได้สบสายตากัน คำพูดที่พลั่งพลูออกมาไม่มีการล้อเล่น มีแต่ความจริงจังออกมาจากปากของน้องจิ้งจอก

"บอส.. ผมดีใจที่ได้เจอบอสครับ.. เรามาจัดการพวกคนชั่วให้หมดโลกนี้กันเถอะครับ"

นาฬิกาที่ในตอนแรกนั้นไม่มี แต่กลับอยู่บนข้อมือของน้องจิ้งจอกตั้งแต่ครั้งเมื่อได้ยินเสียงปริศนาที่มอบพลังของปีศาจให้กับเขา นาฬิกาเรือนนั้นเริ่มขยับเข็ม ไม่ใช่การเดินหน้า แต่เป็นการถอยหลัง
