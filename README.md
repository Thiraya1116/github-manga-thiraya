## Ep.5 Revenge

สิ้นคำประกาศสงคราม บรรยากาศรอบตัวของน้องจิ้งจอกเริ่มอึมครึมขึ้น ความคิดภายในหัวของเขามีแต่ "การแก้แค้น"

เขาตัดสินใจกำจัดปีศาจด้วยแรงแค้น แม้จะต้องขายวิญญาณให้กับปีศาจจริงๆก็ตาม 

แสงสว่างที่ไร้ความสดใสสว่างวาบรอบตัวน้องจิ้งจอก ทำให้เขาหลับตาแนบสนิทโดยอัตโนมัติ ไม่มีใครรู้ว่ามันจะนำพาเขาไปที่ไหน

วิ๊ง

สิ้นเสียงและแสงอันมืดหม่น น้องจิ้งจอกรู้สึกตัวได้ว่า มีบางอย่างผิดปกติ เขาได้ยินเสียงของ...คน?

"...-จอก จิ้งจอก? ฟังอยู่ไหมเนี่ย?" เสียงของคนคุ้นเคยที่เขาจำไม่เคยลืม ไม่สิ.. เขาลืมไม่ได้เสียมากกว่า 

น้องจิ้งจอกแทบจะหัวเราะออกมาลั่น แต่เขาเก็บสีหน้าไว้ได้ 

"ไม่ได้สิ... เราจะทำให้แผนการพังไม่ได้นะ.." เขาคิดในใจ

น้องจิ้งจอกฟังคำพูดของคนตรงหน้าด้วยรอยยิ้มเหมือนปกติ แม้ฝ่ามือของเขาจะเจ็บแสบ และเต็มไปด้วยเลือดที่หยด ติ๋งๆ แต่แรงที่ฝ่ามือของเขาก็ไม่เบาลงเลย 

ความลึกของเล็บที่จิกเข้าไปในเนื้อ ยิ่งลึกเท่าไหร่ ก็ยิ่งเท่ากับแรงแค้นของน้องจิ้งจอกที่มีต่อคนตรงหน้ามากเท่านั้น

"ว่าไง? เห็นคลิปแล้วใช่ไหม?"
"ฉันบอกแล้วว่าบอสของแกน่ะเป็นคนไม่ดี เขาสร้างภาพหัวหน้าสุดแกร่งเฉพาะตอนที่อยู่ต่อหน้าแกเท่านั้นแหละ"

เมื่อเสียงคนตรงหน้าเอ่ยออกมาด้วยน้ำเสียงเยาะเย้ยอย่างชัดเจนแต่น้องจิ้งจอกในอดีตกลับไม่รู้สึกถึงมันเลย เพราะเอาแต่สงสัยในตัวของบอส น้องจิ้งจอกกัดฟันแน่นดังกรอด

"..งั้นหรอ ฉัน... ไม่รู้จะพูดยังไงดีเลย"
"ฉัน.. ขอตัวก่อนนะ"

น้องจิ้งจอกถอยห่างออกมาด้วยสีหน้าผิดหวังที่ตั้งใจทำ   ทำให้คนตรงหน้ายิ้มชะล่าใจ ที่เหยื่อติดกับแล้ว

แต่น้องจิ้งจอกไม่สนใจ ตอนนี้.. เขาอยากเจอ..

อยากเจอคนที่คอยดูแลเขา
อยากเจอคนที่เขารักและเคารพ
อยากเจอ..คนที่เขาหักหลัง

คนที่..เขาลงมือฆ่าเองกับมือ

"บอส"
